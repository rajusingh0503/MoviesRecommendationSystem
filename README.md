# MovieMind - Movie Recommendation System

## Team Name
Dragon Runes

## Project Challenge
Challenge #69 - AI-based Recommendation System

## Project Title
MovieMind - Movie Recommendation Web Application

## Project Description

MovieMind is a Java-based web application that provides personalized movie recommendations based on user preferences such as genre and language.

Users can register, log in, manage their movie preferences, browse movies, rate movies, add movies to their watchlist, and view personalized recommendations.

Administrators can manage movies, view registered users, configure recommendation weights, and monitor system analytics.

## Main Features

### User Features

- User registration
- User login and logout
- Personalized movie recommendations
- Genre preference management
- Language preference management
- Browse movies
- View movie details
- Rate movies
- Rating history
- Add movies to watchlist
- Remove movies from watchlist
- View user profile

### Admin Features

- Admin login
- Admin dashboard
- Movie management
- Add movies
- Update movies
- Delete movies
- View registered users
- Configure recommendation algorithm weights
- View system analytics
